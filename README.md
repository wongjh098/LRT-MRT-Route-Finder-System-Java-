LRT/MRT Route Finder System (Java)

#Project Description
A desktop application developed using Java and JavaFX to help passengers find LRT/MRT routes.

#Features
- Find routes between stations.
- Use the Breadth-First Search (BFS) algorithm.
- Display route information through a graphical user interface.

#Technologies Used
- Java
- JavaFX
- Breadth-First Search (BFS)
